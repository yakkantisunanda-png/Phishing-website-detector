# 🛡️ Phishing Website Detector

**Live Demo:** https://phishing-website-detector-b34p.onrender.com

> A Web Application for real-time URL-based phishing detection using ML model. Built with Python, Flask & Machine Learning.

### 🚀 Features
- 97% Accurate ML Model (Random Forest)
- Detects Fake URLs, IP tricks, @ symbols
- Deployed Live on Render

### 🛠️ Tech Stack
Python, Flask, Scikit-learn, Gunicorn, Render
